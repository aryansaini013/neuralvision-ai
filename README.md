# NeuralVision AI

## Deep Learning Project

NeuralVision AI is a handwritten digit recognition
application developed using Python and Deep Learning.

## Features
- Handwritten digit image upload
- CNN-based digit classification
- Prediction confidence
- Probability visualization
- Interactive dashboard

## Technologies Used
- Python
- TensorFlow and Keras
- Convolutional Neural Network (CNN)
- Streamlit
- NumPy
- Pillow
- Plotly

## Dataset
MNIST Handwritten Digits Dataset.

## How to Run

Install the required libraries:

    pip install -r requirements.txt

Run the application:

    streamlit run app.py

## Objective
To recognize handwritten digits from 0 to 9
using a Convolutional Neural Network.
